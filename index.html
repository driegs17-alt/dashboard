Turn on check-offs for this device

Do this once on each phone or computer. The key stays on this device only.

  1. Open GitHub's key page ↗ (sign in if asked).
  2. Name it Dashboard, set expiration to 1 year.
  3. Under Repository access, pick Only select repositories → dashboard.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it, paste it below.
